# 昆明日均气温预测模型 — 实验报告

| 项目 | 内容 |
| --- | --- |
| 实验名称 | 昆明日均气温预测模型构建与优化 |
| 实验日期 | 2026-09-06 |
| 数据来源 | Open-Meteo 历史气象 API（昆明 25.04°N, 102.72°E） |
| 数据时间范围 | 2020-01-01 ~ 2025-09-05（2075 天） |
| 技术栈 | Python、Scikit-learn、Pandas、Matplotlib、Joblib、Flask |

---

## 一、实验目标

1. 基于昆明历史日均气温数据，构建次日日均气温预测模型
2. 对比线性回归、决策树、随机森林、GBDT 四种模型的预测性能
3. 通过网格搜索 + 时序交叉验证优化随机森林超参数
4. 通过特征重要性分析量化各特征对预测的贡献
5. 将最优模型导出为 pkl 并提供预测 API，验证从实验到落地的完整流程

## 二、数据概况

| 指标 | 值 |
| --- | --- |
| 总天数 | 2075 |
| 日均气温均值 | 15.59℃ |
| 日均气温最低 | -1.9℃ |
| 日均气温最高 | 26.4℃ |
| 日均气温标准差 | 4.72℃ |
| 缺失值 | 0 |

昆明气候温和（"春城"），气温年较差较小，日变化具有较强的自相关性，适合用滞后特征进行时序预测。

## 三、特征工程

### 3.1 特征构造

| 特征类别 | 特征名 | 数量 | 说明 |
| --- | --- | --- | --- |
| 当日气温 | temp_current | 1 | 目标当日日均气温 |
| 时间特征 | month, day, dayofyear | 3 | 月、日、一年中第几天 |
| 季节特征 | season_spring/summer/autumn/winter | 4 | 季节 one-hot 编码 |
| 滞后特征 | lag_1 ~ lag_7 | 7 | 前 1~7 天日均气温 |
| **合计** | | **15** | |

### 3.2 目标变量

`temp_mean_next` = 次日日均气温（通过 `temp_current.shift(-1)` 构造）

### 3.3 数据划分

- **训练集**：2020-01-08 ~ 2024-07-17，共 1653 行（80%）
- **测试集**：2024-07-18 ~ 2025-09-04，共 414 行（20%）
- 严格按时间顺序划分，不随机打乱

### 3.4 防数据泄露措施

1. 时序划分（非随机）
2. StandardScaler 仅在训练集上 fit
3. 交叉验证使用 `TimeSeriesSplit(n_splits=5)`，每折训练集均在验证集之前
4. 滞后特征仅通过 `shift()` 使用历史数据

## 四、模型对比实验

### 4.1 实验设置

| 模型 | 关键参数 |
| --- | --- |
| 线性回归 | 默认 |
| 决策树 | max_depth=10, random_state=42 |
| 随机森林 | n_estimators=200, min_samples_leaf=2, random_state=42, n_jobs=-1 |
| GBDT | n_estimators=200, learning_rate=0.05, max_depth=4, random_state=42 |

### 4.2 测试集结果

| 模型 | MAE (℃) | RMSE (℃) | R² | 排名(MAE) |
| --- | --- | --- | --- | --- |
| 线性回归 | 1.040 | 1.533 | 0.879 | 1 |
| 随机森林 | 1.051 | 1.583 | 0.871 | 2 |
| GBDT | 1.093 | 1.617 | 0.866 | 3 |
| 决策树 | 1.361 | 2.153 | 0.762 | 4 |

### 4.3 结果分析

- 四种模型中，线性回归和随机森林性能接近且最优，MAE 均在 1.05℃ 左右
- 线性回归略优的原因：当日气温与次日气温之间存在近似线性的强自相关关系，线性模型已能很好捕捉
- 决策树性能最差，存在过拟合（单棵树对训练数据记忆过强，泛化能力弱）
- 随机森林通过多棵树投票显著优于单棵决策树，且具备特征可解释性
- **优选随机森林**：虽然 MAE 略高于线性回归 0.01℃，但具备非线性拟合能力、特征重要性输出、对异常值更鲁棒，且两者差距在噪声范围内

## 五、随机森林超参数调优

### 5.1 调优方法

- **工具**：GridSearchCV
- **交叉验证**：TimeSeriesSplit(n_splits=5)（时序 5 折）
- **评分指标**：neg_mean_absolute_error（负 MAE）
- **参数组合数**：3 × 3 × 2 × 2 = 36 组
- **总拟合次数**：36 × 5 = 180 次

### 5.2 搜索空间

| 参数 | 搜索范围 |
| --- | --- |
| n_estimators | [100, 200, 300] |
| max_depth | [None, 10, 20] |
| min_samples_split | [2, 5] |
| min_samples_leaf | [1, 2] |

### 5.3 最优参数

| 参数 | 最优值 |
| --- | --- |
| n_estimators | 300 |
| max_depth | 10 |
| min_samples_split | 5 |
| min_samples_leaf | 2 |

### 5.4 调优前后对比

| 指标 | 调优前 | 调优后 |
| --- | --- | --- |
| 交叉验证 MAE | — | 1.167℃ |
| 测试集 MAE | 1.051℃ | **1.042℃** |
| 测试集 RMSE | 1.583℃ | **1.571℃** |
| 测试集 R² | 0.871 | **0.873** |

调优后测试集 MAE 稳定在 **1.04℃**，远低于 2℃ 的控制目标。

## 六、特征重要性分析

| 排名 | 特征 | 重要性 | 累计重要性 |
| --- | --- | --- | --- |
| 1 | temp_current（当日气温） | 0.9277 | 0.9277 |
| 2 | dayofyear（一年中第几天） | 0.0135 | 0.9411 |
| 3 | lag_1（前1天气温） | 0.0093 | 0.9505 |
| 4 | lag_4（前4天气温） | 0.0088 | 0.9593 |
| 5 | lag_3（前3天气温） | 0.0079 | 0.9672 |
| 6 | lag_2（前2天气温） | 0.0072 | 0.9744 |
| 7 | lag_5（前5天气温） | 0.0064 | 0.9808 |
| 8 | lag_6（前6天气温） | 0.0055 | 0.9863 |
| 9 | month（月） | 0.0048 | 0.9911 |
| 10 | lag_7（前7天气温） | 0.0039 | 0.9950 |

### 关键发现

1. **当日气温是绝对主导特征**（重要性 92.8%）：次日气温与当日气温高度自相关，这是气温时序预测的核心物理规律
2. **季节因子（dayofyear + month）合计约 1.8%**：捕捉年周期季节性变化
3. **滞后特征 lag_1~lag_7 合计约 5.2%**：提供短期趋势信息，其中 lag_1（前一天）贡献最大
4. **前 3 个特征累计贡献 95%**：当日气温 + 季节 + 前一天气温即可解释绝大部分预测方差

## 七、残差分析

- 残差均值接近 0（无系统偏差）
- 残差近似正态分布，大部分集中在 ±2℃ 以内
- 残差与预测值无明显异方差 pattern
- 个别极端天气日（如寒潮、强降雨）残差较大，属于正常现象

## 九、实验结论

1. **模型性能达标**：调优后随机森林测试集 MAE=1.04℃、RMSE=1.57℃、R²=0.873，MAE 稳定控制在 2℃ 以内
2. **当日气温是核心预测因子**（重要性 92.8%），滞后特征和季节因子提供补充信息
3. **随机森林是优选模型**：在性能接近线性回归的同时，具备可解释性和非线性拟合能力
4. **时序防泄露措施有效**：时序划分 + TimeSeriesSplit + Scaler 隔离，确保评估结果可信
5. **从实验到落地闭环完成**：模型导出 pkl + Flask API + 真实数据验证，可独立部署或接入项目1

## 十、后续优化方向

1. 引入滚动均值特征（3日/7日）和气温日较差（temp_max - temp_min），可能进一步提升 R²
2. 尝试 XGBoost / LightGBM 等更先进的梯度提升模型
3. 引入外部变量（如气压、湿度、降水量）作为多变量预测
4. 对极端天气日（寒潮、暴雨）建立专项预测或异常检测机制
5. 接入项目1的实时采集数据流，实现每日自动滚动训练与预测
